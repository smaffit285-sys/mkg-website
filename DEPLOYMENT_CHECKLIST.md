# Deployment Checklist

Use this checklist before any push, pull request, merge, or deployment.

1. Verify the current branch.
2. Verify the remote is `https://github.com/smaffit285-sys/mkg-website.git`.
3. Preview the site locally.
4. Confirm `ourstory.webp` loads in the Our Story section.
5. Confirm all customer actions use MKG-owned routes such as `/book/`, `/review/`, and `/send-photos/`.
6. Search for banned public terms: `SharpBot`, `AI-powered`, `automated`, `razor sharp`, `best in Miami`, and `world-class`.
7. Run `git status`.
8. Run `git diff`.
9. Run `git diff --check`.
10. Stage only named files. Do not use `git add .`.
11. Commit only after visual approval.
12. Push only after approval.
